# Sistema de Cadastro 

Este projeto é um sistema simples desenvolvido em PHP, MySQL, HTML e CSS, com o objetivo de cadastrar e gerenciar pratos e usuários. O sistema permite adicionar, visualizar, editar e excluir informações, utilizando um banco de dados para armazenar os dados.

Também foram utilizados Prepared Statements, uma técnica que ajuda a deixar as consultas ao banco de dados mais seguras e a prevenir ataques de SQL Injection.

O projeto foi desenvolvido como forma de praticar conceitos de programação web, PHP, banco de dados e segurança.
